# Vehicle Sales Data Dashboard 🚗

## Project Overview

This project is an interactive data dashboard developed to explore vehicle listing data and make patterns in the dataset easier to understand.

Using Python, Pandas, Plotly, and Streamlit, I performed exploratory data analysis and transformed the results into interactive visualizations that allow users to explore vehicle characteristics and their relationship with price.

The project demonstrates how raw data can be transformed into a simple analytical tool that makes information easier to explore and interpret.

---

## Business Problem

Vehicle listing datasets can contain large amounts of information about price and vehicle characteristics. Reviewing this information manually makes it difficult to quickly identify patterns and relationships.

The goal of this project was to create an accessible dashboard that allows users to interact with the data and visually explore relevant trends.

---

## Objective

The main objectives of the project were to:

- Explore and prepare vehicle listing data for analysis.
- Identify patterns and relationships within the dataset.
- Create clear and interactive data visualizations.
- Build a web-based dashboard that allows users to explore the information without working directly with the raw dataset.

---

## My Approach

I started by exploring the dataset to understand its structure and the information available.

Using Python and Pandas, I prepared the data for analysis and then created visualizations to explore distributions and relationships between variables.

I used Plotly to create interactive charts, including histograms and scatter plots, and Streamlit to turn the analysis into an interactive web application.

This allowed the analysis to move beyond a static notebook and become a tool that users could explore directly.
