# Vehicle Sales Data Dashboard 🚗

## Project Overview

This project is an interactive web dashboard developed to explore vehicle listing data in the United States and make patterns in the dataset easier to understand.

Using Python, Pandas, Plotly, and Streamlit, I performed exploratory data analysis and transformed the data into interactive visualizations that allow users to explore vehicle prices and their relationship with model year.

🚀 **[View Live Dashboard](https://vehicles-dashboard-zb9r.onrender.com/)**

---

## Business Problem

Vehicle listing datasets can contain large amounts of information about prices and vehicle characteristics. Reviewing raw data manually makes it difficult to quickly identify patterns and relationships.

The goal of this project was to create an accessible dashboard that allows users to interact with the data and visually explore relevant trends.

---

## Objective

The main objectives of the project were to:

- Explore and prepare vehicle listing data for analysis.
- Analyze the distribution of vehicle prices.
- Explore the relationship between model year and price.
- Create clear and interactive data visualizations.
- Build a web-based dashboard that allows users to explore the information without working directly with the raw dataset.

---

## My Approach

I started by exploring the dataset to understand its structure and the information available.

Using Python and Pandas, I prepared the data for analysis and created visualizations to explore distributions and relationships between variables.

I used Plotly to create interactive charts and Streamlit to transform the analysis into an interactive web application.

This allowed the analysis to move beyond static visualizations and become a tool that users can explore directly.

---

## Dashboard Features

### Price Distribution

An interactive histogram allows users to explore the distribution of vehicle prices in the dataset.

### Model Year vs. Price

An interactive scatter plot allows users to examine the relationship between a vehicle's model year and its listed price.

### Interactive Exploration

Users can interact with the dashboard controls to display and explore the visualizations.
